# 校務修課資料分析專案

## 專題：要解決的問題

**大學部學生何時開始修英語授課專業課？不同修課路徑與課程供給、修課前學業表現有什麼關聯？**

本專題以學生跨學期修課紀錄為主，排除大一英文等語言學習課，描述首次修讀、持續修讀、中斷與再進入，並比較學院、推定修業階段、當期英語專業課供給及修課前成績。希望回答：**哪些學生較晚開始修；晚開始是否伴隨較少的早期課程供給；應優先在哪個學院與修業階段檢查開課配置。**這些是待資料檢驗的問題，不預設原因是學生不想修，也不預設英語授課使成績變好。現有觀察資料只能支持關聯分析，不能直接證明因果效果。

目前主要分析使用 `115-0012` 批次的 1051–1151 學期開課與修課資料，從大學部學生連續可見的八學期建立可比較路徑；實際入學年級仍須正式學籍資料核對。研究方法、口徑與彙總結果見[共用資料層與雙專題分析](共用資料層與雙專題分析.md)。用 [`uv` 管理 Python 與套件版本](UV_SETUP.md)；原始校務資料、學生識別碼、資料庫憑證與本機 `outputs/` 不上傳。

## 競賽：教師候選推薦（獨立方向）

競賽情境由教務處輸入一門資工系預計改為英語授課的必修課，系統依同課、正式 EMI、英語授課、相關課程及近期授課紀錄，列出最多三位有可回查證據的教師候選人。候選分數是歷史授課證據指標，**不是教師適任、正式 EMI 資格或可派任機率**；教師身分、當期聘任與排課須人工核對。兩個方向共用開課資料清理與課程連結，但研究問題及結論分開。

## 研究母體與連結

資料期間為 1101–1142 的十個連續學期。以 `student_terms` 的學生系所代碼與名稱，對照 `undergraduate_department_rules.json` 確認大學部學生學期；排除英美語文學系，因該系大一英文開課制度另訂。這是**依修課資料判讀的大學部觀察範圍**，不是校方正式在學名冊、入學年度或實際年級。沒有修課紀錄的學期不在分母內。

主要連結為 `enrollment_records.source_grade_row_id` → `student_course_grade_raw.grade_row_id`；`student_key` → `student_terms(student_key, term_code)`；`offering_id` → `course_offerings`，再接 `offering_english_level`。學生碼僅供程式在記憶體內跨學期連接；資料提供單位仍需確認跨學期識別碼始終穩定。

本分析的「英語授課」使用**開課資料的 `teaching_language_raw = 英語`**。`部份英語`單獨統計，不合併進英語組。研究目標為英語授課專業課程，排除 `LN` 課號以及名稱明示大一英文、進修英文、TOEIC 或英文能力鑑定的課程。它是開課語言標籤的分析，不代表每筆都已經核對正式 EMI 認定名單。

## 欄位判讀與重複列

「曾選入課程」依原始 `allocation_result` 的中選／加選類別及停修判斷；人工退選、衝堂退選、刪除本筆、停開落選與登錄屬性的免修／抵免不計入。只納入狀態為正常的已配對班次。「有效數字成績」另須原始 `registration_attribute_name = 成績已輸入`，成績為 0–100 數字，學分為 0–50 數字。這是本次可重現的研究判讀，不能取代教務處的最終有效修課狀態；課程 60 分門檻結果僅作數字描述。

同一學生、學期、班次若有多筆來源列，先保留一筆作班次計數；若數字成績不同，或與免修／抵免／退選標記並存，將該組視為**狀態或成績衝突**，不進入參與、流向與成績分析。原始資料與重複列均未刪改。沒有成功配對 `offering_id` 的來源列無法判授課語言，不被推成國語或未選英語班。

## 三階段分析

1. **英文分級與後續修課：**只用目標學期之前、已觀察到的大一英文班次級別；同一學期內多個級別時保留未知。統計各級別學生學期的英語課參與率、班次與學分。班次級別是修讀證據，非原始入學考分或免修資格；未知不得當作初級。
2. **相鄰學期流向：**只使用同一學生前後兩個相鄰學期均有大學部修課資料的學期對，統計「未觀察到英語班／有修讀英語班」四種轉移。沒有英語班配對不能證明沒有選課；缺席學期、休學與畢業均無法辨識。
3. **同課同學期成績比較：**限定正學分課程；候選組須同課號、同學期且有國語／英語班；兩語言各至少五筆有效數字成績才入模。先列混合平均分差，再以課號×學期固定差異比較；調整此前可見英文級別、此前所有已觀察成績的學分加權平均、前期均分缺漏及學生系所。未知英文級別保留一類。標準誤按課號聚集，列近似 95% 信賴區間。另排除最大課號重估，觀察單一大課對結果的影響。

第三項比較的結果單位是**課內分數**。不同班可能由不同教師出題、評分，學生也非隨機分班；目前沒有完整英檢前測、選課申請與名額歷程、教師 ID 或共同考試分數。因此所有差異只稱「調整已觀察背景後的關聯」，不能說已排除英文能力偏差，更不能宣稱英語授課造成學習成果提升。若研究「英文能力進步」，需另取得可比較的修課前後測。

原資料專案的班次級別核對、免修與抵免證據及來源文獻見 [原資料專案 README](../../../latex%20編譯/ncu_course_flow_import/README.md)。此處的相對連結只供本機對照，程式執行不依賴它。

> [!NOTE]
> **競賽教師推薦的權重規劃：**目前的 0–100 分是人工設定的授課證據指標，尚不是教師適任或可派任機率。後續請教務處承辦人與系所主管，成對比較「同課經驗、正式 EMI 經驗、近期授課」等構面的重要性，依層級分析法（AHP）計算權重並檢查判斷一致性；行政資格與排課仍須另行人工核對。方法來源：[Saaty（1990）, *How to make a decision: The Analytic Hierarchy Process*](https://doi.org/10.1016/0377-2217(90)90057-I)。
