# EMI 師資證據助理

<!-- impeccable:product-schema 1 -->

## 對象與任務

系所承辦人規劃將資工學士班必修課改為 EMI 時，需要整理候選教師的歷史授課證據，供系所討論。正式服務單位與日常流程仍待訪談確認。

競賽以團隊操作、三分鐘投影為主要場景，也支援評審自行試用。展示成功的判準是評審能指出一項候選差異，從摘要找到支持該說法的原始授課紀錄，並說出一項仍需人工核對的條件。

## Platform

web

介面以桌面瀏覽與投影展示為設計範圍，使用繁體中文，現有前端採 React、TypeScript 與 Vite。

## 證據與使用限制

來源為正常開課、單一教師的歷史授課紀錄。0–100 分表示歷史證據分數；教學品質、當期適任性與可指派性仍需另行評估。授課語言與正式 EMI 註記分開呈現，缺值顯示「未知」。

實際開課資料只在本機產生摘要。對外展示可使用 [CE2005 合成案例](backend/case.json) 示範從摘要追溯至授課紀錄。

## 展示設計與 UI 選型

- 首屏採系所課程審議資料表的版式。課號、資料來源與候選比較置頂，研究背景收在可展開區。暖白底配墨色正文，深藍用於操作與引用。投影正文以 20px 為起點，課號、學期及分數用等寬數字對齊。
- 以 CE2005 開場。桌面按候選人分欄，按同課授課、英語授課、正式 EMI 等證據分列；資料未知直接寫「未知」。歷史證據分數列在事實之後。
- 勾選候選人後產生摘要。點引用時在摘要旁展開學期、課程、授課語言與 EMI 註記。使用鍵盤也能開啟紀錄並返回原引用。生成中或失敗時仍可閱讀已取得的授課證據。
- AI 展示用清楚標示的合成案例，實際開課資料使用本機摘要。兩種模式都列出待核對的聘任資格、意願、負荷與時段。
- 選用 shadcn/ui，在現有 Vite 專案整合 Tailwind CSS，由團隊維護匯入的元件。以 Table 並排比較候選人、Checkbox 勾選比較對象，並以受控 Collapsible 展開摘要所引用的授課紀錄。引用按鈕與紀錄共用識別碼，方便鍵盤使用者查閱後回到原句。[shadcn/ui 元件文件](https://ui.shadcn.com/docs) · [Vite 整合](https://ui.shadcn.com/docs/installation/vite/)
